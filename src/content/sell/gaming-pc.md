## รับซื้อคอมเกมมิ่งมือสอง — ส่งสเปกเช็กราคาก่อนได้

BuyHub รับซื้อ **คอมเกมมิ่งมือสอง** และพีซีสเปกเล่นเกมที่ยังมีตลาดมือสองชัดเจน หากคุณต้องการขายคอมที่ประกอบเองหรือคอมเกมมิ่งสำเร็จรูป แนะนำส่ง “รายการสเปก” และรูปเครื่องผ่าน LINE **@buyhub** เพื่อประเมินราคาฟรีก่อนตัดสินใจขาย

คอมเกมมิ่งเป็นสินค้าที่ราคาเปลี่ยนตามสเปกและสภาพจริงมาก เช่น การ์ดจอ CPU แรม SSD/ฮาร์ดดิสก์ ชุดน้ำ/พัดลม เคส และการใช้งานหนัก ทีมงานจึงขอข้อมูลให้ครบเพื่อให้แนวราคาที่แจ้งมีเหตุผลและใกล้เคียง

## รับซื้อคอมเกมมิ่งแบบไหนบ้าง

โดยทั่วไปสามารถส่งมาประเมินได้ เช่น

- คอมเกมมิ่งประกอบ (Custom PC)
- คอมเกมมิ่งแบรนด์ (ตามรุ่น/สเปก)
- เครื่องที่มีการ์ดจอแยกและสเปกเหมาะกับตลาดมือสอง

กรณีที่เครื่องมีอาการ เช่น เปิดไม่ติด จอฟ้า รีสตาร์ทเอง อุณหภูมิสูงผิดปกติ ยังสามารถส่งรายละเอียดมาให้ประเมินได้ แนะนำแจ้งอาการตามจริงเพื่อให้ประเมินได้ตรงขึ้น

## ปัจจัยที่ใช้ประเมินราคา

- CPU / GPU (รุ่นและสภาพการทำงาน)
- RAM (ขนาด/ความเร็ว) และการทำงานปกติ
- Storage (SSD/HDD) และสภาพการใช้งาน
- เมนบอร์ด/PSU/ชุดระบายความร้อน
- สภาพเคส (ฝุ่น สนิม รอยบุบ) และการจัดสาย/พัดลม
- ผลทดสอบ/การใช้งานจริง (ถ้ามี)
- ราคาตลาดมือสองช่วงนั้น

## ต้องส่งข้อมูลอะไรให้ประเมินไว

1. รูปเครื่องภายนอก + ภายในเคส (ถ่ายให้เห็นชิ้นส่วน)
2. รายการสเปก (CPU/GPU/RAM/SSD/HDD/PSU/เมนบอร์ด)
3. แจ้งอาการใช้งาน/ปัญหา (ถ้ามี)
4. อุปกรณ์ที่มี (กล่องการ์ดจอ/อุปกรณ์เดิม ถ้ามี)
5. จังหวัด/พื้นที่

## เรื่องข้อมูลส่วนตัวก่อนขายคอม

แนะนำสำรองข้อมูลและลบข้อมูลส่วนตัวออกจากไดรฟ์ก่อนส่งมอบ หากไม่แน่ใจเรื่องการล้างข้อมูล สามารถดู [คู่มือเตรียมสินค้าก่อนขาย](/คู่มือเตรียมสินค้าก่อนขาย) หรือทักถามทีมงานได้

## ขั้นตอนการขาย (สรุป)

1. ส่งรูป + สเปกผ่าน LINE **@buyhub**
2. รับแนวราคาและคำแนะนำสิ่งที่ควรเช็ค
3. ตกลงราคาและนัดตรวจ/ส่งมอบ
4. ตรวจสอบสเปก/สภาพ และรับเงินตามขั้นตอน
